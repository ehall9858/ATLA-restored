# CK2 assigns trait ids by load order (files alphabetical, then top-to-bottom).
# Adding a trait earlier in the load order shifts every later trait id and
# corrupts existing save games. Appending here gives them fresh ids (505/506)
# and leaves all pre-existing trait ids untouched.
# ---------------------------------------------------------------------------
